## Approach

- **Widget extension** generated by `@bacons/apple-targets` from
  `apps/mobile/targets/workout-activity/` (`type: widget`, deployment 17.0).
  Lock screen + Dynamic Island views; the clock is
  `Text(timerInterval:pauseTime:)`, so it runs without the app.
- **`_shared/`** (compiled into app and extension): `WorkoutActivityAttributes`
  and the Pause/Resume `LiveActivityIntent`s. They run in the app process,
  update the activity directly and post a `NotificationCenter` event.
- **Local module `modules/workout-live-activity`**: `start / setPause / setKcal
  / end / getState` + `onStateChange` event. Keeps its own copy of the
  attributes (a pod cannot see app-target types); a Vitest test asserts both
  copies are identical.
- **Local module `modules/health-energy`**: `HKStatisticsQuery` cumulative sum of
  `activeEnergyBurned` (de-duplicates iPhone + Watch). No data / denied → `null`.
- **JS**: `WorkoutLiveActivity` interface (`index.ios.ts` adapter, `index.ts`
  no-op). A controller subscribes to the draft store (0010): start on workout
  start, `setPause` on pause (0011), `end` on finish/discard. Pure
  `reconcile(draft, activityState)` on mount and on app active: end orphans,
  restart on mismatch, adopt a lock-screen pause. kcal read at start, on app
  active, and every 60 s while not paused.
- **Finish link** `traininghub://workouts/active?action=finish` → `Alert`
  confirm → existing `finishWorkout`.
- **app.json**: `ios.appleTeamId`, `NSSupportsLiveActivities`,
  `NSHealthShareUsageDescription`, `com.apple.developer.healthkit`, plugin.
  App deployment target stays 15.1 (`@available` guards).

- Pause/Resume intents run in the app process, update the activity and reach JS.

### Alternatives considered

- **Voltra / expo-widgets** — rejected: require App Groups (unavailable on the
  free team); expo-widgets is alpha on SDK 55.
- **iOS 26 `HKWorkoutSession` on iPhone** — rejected: no heart-rate on the
  phone (poor calories for lifting), needs a watch app for full metrics, and
  writes a workout to Health.
- **Finish in the background** — rejected by the owner.
- **Pause as a deep link** — kept as plan B if intents regress.
